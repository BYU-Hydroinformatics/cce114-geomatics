# CCE 114 — Geomatics

Course materials for **Civil and Construction Engineering 114 (Geomatics)** at Brigham Young University, taught by Dr. Dan Ames.

**📖 Read the course site: https://byu-hydroinformatics.github.io/cce114-geomatics/**

The site is built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) from the Markdown in [`docs/`](docs/) and redeploys automatically on every push to `main`.

| Where | What |
| --- | --- |
| [docs/assignments/](docs/assignments/) | Lab assignments 1–11 (one folder per lab, with images), quizzes and experiences, final project |
| [docs/schedule.md](docs/schedule.md) | The 15-week schedule (Tuesday concepts, Thursday hands-on), generated by `tools/build_schedule.py` |
| [docs/lectures/](docs/lectures/) | One page per class day, linking the slide decks |
| [slides/](slides/) | Marp web slide decks, one folder per day, built by the deploy workflow |
| [docs/policies/](docs/policies/) | Grading, attendance, exams, university policies, and the [AI Use Policy](docs/policies/ai-policy.md) |
| [tools/](tools/) | Conversion pipelines (Google Docs and PowerPoint to Markdown), the schedule generator, and QGIS screenshot drivers |
| [HANDOFF.md](HANDOFF.md) | Status of the GitHub-based course, how things are generated, and what still needs a person |

To preview locally: `pip install mkdocs-material mkdocs-github-admonitions-plugin && mkdocs serve`
