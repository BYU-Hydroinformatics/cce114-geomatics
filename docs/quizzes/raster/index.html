The short version of the hour:
A raster is cell size, extent, rows and columns, and a no-data value
No-data is not zero — zero is a score, no-data is "do not compute"
Adding lets a strong score rescue a weak one; multiplying makes a zero fatal
Align the grids before the Raster Calculator, not after
The data model should match the phenomenon — continuous surfaces are the raster case.
